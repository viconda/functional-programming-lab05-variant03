# Лабораторная 05. Рекурсивные функции, вариант 3

Дисциплина CSE6742, Функциональное программирование. Швачкина Виктория.

Репозиторий содержит только лабораторную работу 5. Выполнены задания 1–5,
вариант 3 и дополнительный арифметический парсер. Вариант 3 включает
трибоначчи, все подстроки строки и число путей в сетке.

Требуется Python 3.10 или новее. Используется только стандартная библиотека.

```sh
python -X utf8 lab.py --section all
python -X utf8 lab.py --section tribonacci
python -X utf8 lab.py --section tests
python -X utf8 -m unittest -v tests_lab
```

Всего 35 практических блоков. `lab05/tools.py` содержит декоратор instrument.
`tests_lab.py` содержит 19 тестов, включая граничные значения, ошибки,
корректность парсера, отсутствие мутаций и сброс замкнутых счётчиков.
Запускайте без `-O`, чтобы не отключать assert.

`lab_results.json` хранит реальные замеры на Python 3.12.14. При обычном
запуске программа явно помечает сохранённые результаты. Для нового
эксперимента выполните `python -X utf8 lab.py --section all --refresh`.
Время и точная граница RecursionError зависят от версии Python и стека
вызовов. Изменение лимита производится только внутри отдельного процесса.

Для путей принята сетка из m строк и n столбцов клеток: от левой верхней
к правой нижней клетке можно двигаться вниз и вправо. Подстроки перечислены
по позициям с повторениями; дополнительно проверено включение пустой строки.

Отчёт Word с 8 письменными ответами, таблицами и реальными скриншотами
передаётся отдельно. Титульные листы и отчёты здесь не публикуются.
